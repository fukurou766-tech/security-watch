# 🔐 Security Watch — 個人用脆弱性情報

> **非公開リポジトリで閲覧する方式です。Webサイトとしては公開しません。**

## 📱 Androidで見る

GitHubアプリまたはChromeでこのPrivateリポジトリの **README.md** を開くだけです。GitHubへのログインが必要です。

**最新情報を見る:** [📋 日本語レポート](REPORT.md)

**データを見る:** [📦 データ一覧](data.json)

## ⏰ 自動更新

GitHub Actionsで毎日 **日本時間 9:17ごろ** 更新します（GitHubの都合で遅延・不実行の場合があります）。Actions →「脆弱性情報を毎日更新」→「Run workflow」で手動更新できます。

## 情報源と翻訳

- JVN iPedia：日本語RSS（タイトル・概要）
- CISA KEV：悪用が確認された脆弱性。**製品名・CVE番号は原文**、説明は日本語の簡易機械翻訳（外部翻訳APIなしの場合は英語原文を表示）。
- 「緊急」はCISA KEVへの掲載を表し、CVSSスコアを意味しません。

情報の正確性は公式リンクで確認してください。対象製品・バージョンの確認なしに自社影響を断定しないでください。
